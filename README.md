# Amazon Sales Data Analysis

A data analysis project exploring Amazon sales transactions to uncover trends in product performance, customer behavior, fulfillment patterns, and regional sales distribution.

---

## Overview

This project applies exploratory data analysis to a real-world Amazon sales dataset. The goal is to extract meaningful business insights — identifying what sells, where, and how effectively — and translate those findings into clear, actionable recommendations.

---

## Objectives

- **Sales Overview** — Understand revenue trends and order volume over time
- **Product Analysis** — Identify top-performing categories and size preferences
- **Fulfillment Analysis** — Compare fulfillment methods and evaluate delivery outcomes
- **Customer Segmentation** — Distinguish B2B vs. B2C purchasing patterns
- **Geographical Analysis** — Map sales performance across states and cities
- **Business Insights** — Summarize findings into concrete recommendations
